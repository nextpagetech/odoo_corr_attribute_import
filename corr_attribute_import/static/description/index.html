Corrugation Attribute Import

Imports product attributes and attribute values from XLSX or CSV files using readable names instead of technical IDs.

Overview

Corrugation Attribute Import provides a wizard for importing product attributes and product attribute values. It supports XLSX and CSV files, maps flexible column headers, and reports created, updated, and skipped records after import.

Key Features

Attribute import

Creates or updates product attributes by name, create-variant mode, and sequence.

Attribute value import

Creates or updates product attribute values by attribute name and value name.

XLSX and CSV support

Reads XLSX workbooks or CSV/TXT files through a wizard upload field.

Import modes

Supports importing attributes and values together, attributes only, or values only.

Missing attribute option

Can create missing attributes while importing values when the option is enabled.

Import result log

Shows a summary of created, updated, and skipped rows after processing.

How It Works

  1. Open Attribute Tools and select Import Attributes/Values.
  2. Choose the import mode: attributes and values, attributes only, or values only.
  3. Upload an XLSX, CSV, or TXT file.
  4. Enable or disable updating existing records and creating missing attributes as needed.
  5. Run the import and review the result log in the wizard.

Supported Columns

  • Attributes: Name, Create Variant, Sequence.
  • Values: Attribute, Name, Sequence, and optional Weight when the related custom field exists.
  • Create Variant values supported by the wizard include always, no variant, and dynamic.

Benefits

  • Reduces manual product attribute and value entry.
  • Avoids requiring technical IDs in import files.
  • Supports controlled updates to existing product attribute data.
